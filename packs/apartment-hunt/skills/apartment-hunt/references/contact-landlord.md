# Contacting a landlord

You draft; the user sends. Never send a message, submit an application, book
a tour, or pay anything on the user's behalf.

## Before drafting

1. If the listing has not been vetted, run `vet-listings` on it first.
2. If `scam.risk` is `high`, do not draft anything. Tell the user why
   (`signals`) and suggest searching the address and photos on other sites.
3. If the landlord asks for money before a viewing (deposit, holding fee,
   application fee by Zelle, wire, crypto, or gift card), tell the user not to
   pay. A legitimate landlord shows the unit first, in person or on a live
   video tour, and takes payment after a lease is signed.

## The message

Short, specific, and easy to say yes to:

- Which listing (address or title and the link) and the asking price.
- Who the user is in one line, and their move-in date.
- One or two concrete questions the listing leaves open (laundry, pets,
  parking, utilities, lease length).
- A request to see it, with two or three times the user is free.

Use only facts the user gave you. Leave placeholders like `[your name]` or
`[move-in date]` for anything you don't know; never make up income, jobs, or
references.

Write the draft to a file (for example `message-<short address>.md`) and show
it in the chat. Remind the user to send it from their own email or the
listing site.
